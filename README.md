# Ізометричні ігри

Три інтерактивні ізометричні сцени на одній сторінці, перемикаються вкладками зверху.

- **Fig 1 · Київ · енергосистема:** https://yurimykolyshyn.github.io/kyiv-power/#kyiv
- **Fig 2 · Диско · вечірка:** https://yurimykolyshyn.github.io/kyiv-power/#disco
- **Fig 3 · Бармен · чотири стійки:** https://yurimykolyshyn.github.io/kyiv-power/#bar

## Fig 1 · Київ · енергосистема

Ізометрична браузерна гра: карта Києва з десятьма районами, у кожному свій житловий будинок, і трансформатор із рубильниками. Вимкнений рубильник знеструмлює свій район.

### Керування

- `1`–`9`, `0` — перемкнути рубильник району
- `←` `→` — вибрати рубильник, `пробіл` — перемкнути
- клік по рубильнику, будинку чи району

Генерація з часом коливається. Якщо навантаження перевищує її довше ніж на 5 секунд, захист вимикає все місто. Тримай навантаження нижче генерації і світло в якомога більшій кількості районів.

### Звідки цифри

Споживання районів розподілене пропорційно до кількості населення (на 1 січня 2016 р., остання повна таблиця по всіх районах; [Вікіпедія: Адміністративно-територіальний устрій Києва](https://uk.wikipedia.org/wiki/Адміністративно-територіальний_устрій_Києва)). ## Fig 2 · Диско · вечірка

Танцпол зі світловими плитками, диско-куля з відблисками по залу, діджейський пульт, колонки і світломузика: три прожектори й індикатори НЧ / СЧ / ВЧ реагують на звук, голови танцюристів підсвічуються кольором променя, у який вони потрапили. Чотири власні треки синтезуються в браузері (WebAudio), без аудіофайлів.

- `1`–`4` — трек (Дискотека 77, Нічний Київ, Фанк-сода, Неоновий Дніпро), `←` `→` — попередній / наступний
- `пробіл` — стоп / старт, `L` — режим світла: музика, стробо, вимк
- кнопки під сценою або на пульті

## Fig 3 · Бармен · чотири стійки

Аркада в пабі «Траллебус»: чотири стійки, відвідувачі йдуть від дверей до кранів. Наливай кухлі й пускай їх по стійці, лови порожні, збирай чайові. Мінус життя, якщо гість дійшов до крана, повний кухоль злетів зі стійки або порожній розбився.

- `↑` `↓` — стійка, `←` `→` — бігти вздовж стійки / назад до крана
- `пробіл` — налити (досить короткого натискання), кухоль поїде, щойно наповниться
- кнопки під сценою для телефона

Один HTML-файл, без залежностей і збірки.

Шаблон і ізометричне ядро: [iso-glow](https://iso-glow.vercel.app) (MIT), на основі iso-figure. Див. `LICENSE-iso-glow`.
